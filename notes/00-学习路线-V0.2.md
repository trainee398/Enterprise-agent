## 0. 完成后你应能不看笔记做到

1. **口述** 主动式 Agent 与企业 Chatbot 的差别，以及 L0–LX 各层在测什么。
2. **手绘** 任务 A 从逾期事件到核实追问、再到升级的闭环，并标出每步的证据。
3. **写清** Fact / Derived Fact / Assessment / 责任归因的边界，以及 AI 停在哪。
4. **设计** 每层的最小验收：输入/输出契约、判定方式（代码 / IR / Judge / 人工）、3–5 条黄金用例。
5. **定位** 一条链路缺陷该先查哪一层、看什么审计证据。
6. **对比** Rovo / Glean / Copilot Studio / ServiceNow：哪些是行业标配，哪些才是我们该自建并测的。

对应 7 份文档应达到「可以带进项目讨论」的完整度，而不是骨架。

## 4. 课次计划（可直接勾选）

每课次固定四件产出，缺一不算完：

1. **任务 A 续写一幕**（同一案例，不另起炉灶）
2. **该层 3–5 条黄金用例**（正/负/边界至少各 1）
3. **一条缺陷定位练习**（给定症状，写出查层顺序与证据）
4. **90 秒会议表达**（写进当课笔记末尾）

并回填：`glossary.md` + 对应 `docs/` 小节。

## 5. 贯穿规则

1. **同一条任务 A 贯穿到底。** 每课次只加一幕，不新开案例，除非该层（如销售额冲突）必须换镜头。
2. **评测左移。** 第 6 课禁止第一次出现某层指标；若缺，回前序课次补，不在收口课现编。
3. **确定性优先。** 能代码判定的（日期、收件人、权限、禁止动作、schema）不用 LLM-as-Judge。
4. **治理三次落地。** U2b 检索权限 · U5c 回复注入 · U6 审计与门禁。
5. **竞品早打预防针。** U5a 已做 15 分钟雷达；U7 再深挖。避免中途把 Rovo 已有能力设计成自研亮点。
6. **课次结束才算学完。** 笔记 + glossary + 文档小节 + 四件产出，缺文档回填等于没结束。
