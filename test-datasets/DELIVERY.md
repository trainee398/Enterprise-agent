## 📚 关键设计原则（已实现）

### ✅ 真值先于产品结果
- Truth 独立定义
- 不用模型回答反推
- 所有事实可溯源

### ✅ 分层判定
- Retrieval: 看 Top-K
- Answer: 拆成 4 维
- UX: 观察任务完成
- Lifecycle: 状态时间线

### ✅ 一个变量原则
- 每个用例测一个主要维度
- 格式变体只改格式
- 版本文档只改版本

### ✅ 能代码判定的不用 Judge
- 数字、日期、人名 → code
- 引用存在、禁用词 → code
- 责任归因、语气 → rubric
- 复杂推理 → manual

### ✅ 开源资源管控
- 登记制度
- A/B/C 等级
- 不替代门槛
- 保留映射
