# 当前一期测试准备：快速开始

> 整理日期：2026-09-08。原 RAG 快速启动指南已存入[历史目录](history/2026-09-03/GETTING_STARTED.md)。

1. **先看范围。** 阅读[当前范围记录](../docs/00-知识库一期范围与待确认事项.md)，确认本期是文档管理，并分清已记录方向与待确认行为。
2. **先观察一个入口。** 使用[简化原型](../docs/11-知识库一期原型方向与图片生成提示词.md)，不给讲解，记录首次使用者如何找到上传、理解位置和可见范围。静态原型仅验证理解。
3. **确定这次测什么。** 在[提测草案](../docs/10-知识库一期提测用例草案.md)中按实际版本标记适用性；从第 0.1 节的一条流程开始，不直接执行整套旧 RAG 用例。
4. **准备少量样本。** 确认格式后，从 DOC-01、02、03 等源稿选择短文、标题/列表和表格。根据实际支持制作必要变体和一个可复现失败样本；检查默认位置、权限和保存规则。
5. **有可操作版本再执行。** 上传 → 打开 → 改一处 → 保存重开 → 找回。状态和已确定权限贯穿检查；随后扩展已纳入范围的异常、更新、恢复等用例。
6. **保存真实证据。** 在 `runs/<build>/` 记录版本、用例、样本、账号、实际结果与证据；失败项补最短复现，修复后记录回归。结束后再更新状态。

尚未确认、没有环境或缺样本的用例分别记待确认、阻塞或未执行；不要算作通过。已设计、文件存在、已审核、已冻结、产品通过是不同状态。
