## 🎓 学到的开源资源使用方法（v2.0 核心）⭐

### 三层组合策略
```
第 1 层: 自建数据（门槛基线）
  - 53 条种子用例
  - 13 条真值事实
  - 基于真实业务场景

第 2 层: 开源提取（快速扩展）⭐
  - 提取 Schema 和维度
  - 基于自建数据实例化
  - 5-8h 新增 10-15 条

第 3 层: 开源校准（可选）
  - 少量原数据（5-10 条）
  - 明确标记为校准集
  - 不混入发布门槛
```

### 提取而非复制
```yaml
正确做法:
  ✅ 从 BEIR 提取 "干扰文档设计模式"
  ✅ 适配到 "任务A vs 任务B"
  ✅ 基于自建真值实例化
  ✅ 保留原始出处信息

错误做法:
  ❌ 直接复制 BEIR 的生物医学问答对
  ❌ 用开源平均分做发布门槛
  ❌ 全量下载 MS MARCO（几百万条）
```

### 三步提取法
```
步骤 1: 提取 Schema（10-20 min）
  → 幻觉四分类、qrels 结构、无答案三分类

步骤 2: 适配到自建数据（30-60 min）
  → 基于任务 A 的真值创建新用例

步骤 3: 少量原数据校准（可选，1-2h）
  → 5-10 条用于检索基线校准
```
