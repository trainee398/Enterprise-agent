## 现在先看什么

当前工作是知识库一期的文档管理。领导最新补充的目标是：容易上手，找到值得借鉴的好用之处，先把一个点做好。我们建议先验证“打开就能放资料，不用先想怎么分类”；这个具体切入点仍是讨论方案。

| 阅读顺序 | 文档 | 用途与状态 |
| --- | --- | --- |
| 1 | [当前范围与待确认事项](docs/00-知识库一期范围与待确认事项.md) | 当前口径入口：区分口述方向、个人体验、设计建议和待确认行为 |
| 2 | [竞品调研与 Markdown 一期设计建议](企业Agent知识库竞品调研与Markdown一期设计建议.md) | 给领导讨论的调研材料；含个人体验、六张截图、候选能力和简化页面方案 |
| 3 | [一期原型方向与图片生成提示词](docs/11-知识库一期原型方向与图片生成提示词.md) | 按最新简化方向出图；尚无产品实测结论 |
| 4 | [一期提测用例草案](docs/10-知识库一期提测用例草案.md) | 先看首轮任务，再从候选用例中选择已确认范围；尚未执行 |
| 5 | [测试资产入口](test-datasets/README.md) | 查看现有语料、一期待补文件、后续 RAG 用例及执行状态 |

给领导讨论时优先使用第 1–3 项；准备测试时使用第 4–5 项。

## 为什么以前的知识库材料不一样

| 材料阶段 | 当时的理解 | 现在怎么用 |
| --- | --- | --- |
| 企业 Agent 学习 | 感知 → 事实 → 判断 → 行动 → 跟进 → 升级 | 长期学习与评测框架，保留，不作为一期功能要求 |
| 早期知识库 V1 预研 | 上传 → 解析/切块 → 检索 → 问答/引用 | 文档 08、09 与原 RAG 数据集，标为后续储备 |
| 当前知识库一期 | 上传 → 转成 MD → 检查 → 修改保存 → 找回维护 | 当前工作范围，具体格式与能力还要确认 |
| 最新体验建议 | 减少开始前的选择，首页突出上传，搜索和最近资料承接 | 当前原型讨论方向，默认归属与权限尚未定案 |

旧文件名里的“V1”沿用历史命名，不代表当前一期口径；旧文中的“本周”“当前”“P0”按当时语境阅读。
